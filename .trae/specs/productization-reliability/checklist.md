# Checklist

- [x] 数字人持久化：创建后重启应用能恢复该数字人及其状态
- [x] 数字人 CRUD 与默认接口可用（列表/详情/默认/改名/删除）
- [x] 构建任务状态机：部分失败后重试仅重跑失败阶段，不重复创建远程资源
- [x] 取消/重试/清理均有可追踪结果，界面不显示"已取消但后台不可追踪"
- [x] 构建任务非线性依赖，job 状态持久化，重启后仍可跟踪
- [x] 统一错误协议：错误含 code/user_message/technical_message/retryable/recommended_action/request_id/details

- [x] 前端统一 API client 解析错误、展示友好信息、支持复制 request_id、按 retryable 控制重试
- [x] App 启动自动恢复默认数字人、未完成构建任务、最近会话
- [x] 对话为 SSE 流式，文本 token 逐步显示，不等待 TTS
- [x] 停止生成、重新生成、编辑重发可用
- [x] TTS 失败不影响文本回答；记忆生成失败不阻塞主回答
- [x] 会话模型支持多会话：标题/归档/删除/清空/搜索/分页

- [x] 结构化记忆：分类/置信度/用户管理（列表/编辑/删除/确认/拒绝/清空）
